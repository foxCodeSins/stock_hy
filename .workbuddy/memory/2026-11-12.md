## 端口调整（16:34，上文 8787 已废弃）

- 用户反馈 8787 冲突；实测 8787 确有其它程序监听（HTTP 返回 `{"error":"未知接口"}`，非本系统），8899 空闲 → **默认端口改为 8899**，访问 http://localhost:8899。
- `server.js`：拆出 `PREFERRED_PORT`（`process.env.PORT` 可覆盖）与 `ACTIVE_PORT`（实际端口）；新增 `startListen()` 遇 `EADDRINUSE` 自动顺延最多 15 次，控制台打印实际地址；`/api/health` 与 dashboard `meta.port` 均返回实际端口；启动后 300ms 后台预热一次 dashboard，使首屏与数据源健康状态立即可用（实测首屏 0.5 秒、4/4 在线）。
- 坑（已修）：重试时若沿用 `server.listen(port, cb)`，每次调用都会新增一个 `listening` 回调且不清除，最终成功会打印多个历史端口。改为具名 `once('error')` + `once('listening')`，任一分支先 `removeListener` 清理两个监听器。
- 本机 8900 也被占用（无 HTTP 服务，疑似系统保留端口），实测顺延链路 8899→8900→8901 正常且只打印一次启动信息。
- `public/app.js` 页脚数据源区显示当前服务端口；`start.bat` 提示以控制台输出地址为准。

## 新增「涨停回调到支撑位」模块（网站开发，已交付）

- 需求：新增短线个股推荐模块，类似划线支撑位/压力位，要有 K 线图与划线解释。
- 实现：零新增文件，改 6 个现有文件（`server.js` / `lib/datasource.js` / `lib/analytics.js` / `public/index.html|app.js|styles.css`）。
  - `datasource.js`：新增 `getRecentLimitUpPools(days)` 回溯东财历史涨停池（近 8 个交易日，10 分钟缓存）；`cached()` 增加 validate 实现「空结果不缓存」；日K重构为 `getKlineData()`（腾讯前复权优先，失败自动降级新浪不复权并返回 source/adjusted 口径），`getKline()` 保持数组兼容；`getHealth()` 给备用源打 standby 标记，不参与在线数统计。
  - `analytics.js`：新增 `pullbackAnalysis()` / `pivotClusters()` / `countTouches()` / `PULLBACK_METHOD`。真实日K识别涨停日（板块阈值）、波段高低点；按缺口下沿/涨停实体/起涨低点/前高转支撑/斐波那契生成水平位；局部极值触碰计数；支撑压力互换；六因子评分 + 四档结论；输出 chart（60 根 + MA + 划线 + 观察区）。
  - `server.js`：新增 `/api/pullback`（独立 3 分钟缓存 + force），按回调天数分层取样 42 只、并发 4 拉日K、应用全局筛选，返回 meta/summary/methodology/list。
  - 前端：新 tab `?tab=pullback` 懒加载；左候选列表 + 右详情联动；**零依赖原生 SVG K 线图**（蜡烛/成交量/MA5-10-20/水平支撑压力线/右侧标签避让/涨停标记/回踩观察区/hover title）；划线解释逐条给依据、触碰次数、距现价、来源，另有完整清单、动态均线、条件化观察框架、数据溯源、完整免责声明。
