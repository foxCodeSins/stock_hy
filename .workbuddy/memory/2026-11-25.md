## 历史优势组合：彩色边框改为动态标记高晋级率组合
- 用户反馈：截图里「中性 44.4% / 45.5%」等晋级率也高，为什么没一起标记。原因是 `dragonEdgeStats().marks` 与前端 `DG_EDGE_META` 都写死为「空间板 / 累计板龙 / 题材龙 + 一致加速」三类。
- `lib/analytics.js`：marks 改为实时动态计算——样本 `n >= minSample(8)` 且晋级率 `>= max(30%, 全样本基准 + 8 个百分点)`；按晋级率降序返回，新增 `markRule`（baselineRate/minRate/minSample/logic），note 同步说明规则。`dragonEdgeMarks(pools, history, marks)` 接受 marks，兼容旧调用的固定三类回退。
- `server.js`：看板与 `/api/ladder` 的标记都传入当前 `edgeStats.marks`，角标不再只覆盖一致加速。
- `public/app.js`：删除 `DG_EDGE_META`，`dgEdgeOf()` 按 `role|dtype` 在 `S.edgeStats.marks` 中判定，颜色按 ≥45% 红 / ≥35% 紫 / ≥30% 蓝分档（`EDGE_TONES`）；矩阵单元格边框按同一档位上色；说明文案改为动态阈值；CSS 类从 `edge-space/cum/theme` 改为 `edge-high/mid/low`（颜色走内联 CSS 变量）。
